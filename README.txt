NCU LOVE FROM THE HILL
Northern Caribbean University Alumni Federation — New Jersey Chapter
2026 Interactive Alumni Scrapbook

HOW TO OPEN LOCALLY
Open index.html in a modern browser. The scrapbook itself and its music can run from the included files.

MUSIC
The included track is music.mp3. Clicking OPEN MEMORIES starts the music from the beginning of the scrapbook. Use the PLAY MUSIC / PAUSE MUSIC button at the bottom right to control playback. The audio player itself is intentionally hidden.

GITHUB PAGES
Upload the CONTENTS of this folder to the root of a public GitHub repository so index.html is at the repository root. Then enable GitHub Pages from Settings > Pages > Deploy from a branch > main > /(root).
